# Guide enseignant — campagne V2

## Organisation d'une séance

Le chapitre 1 est l'aventure originale de six indices. Les chapitres 2 à 7 sont six activités
indépendantes de difficulté croissante. Le chapitre 2 est disponible immédiatement ; les suivants se
déverrouillent dans l'ordre. La sauvegarde automatique permet d'interrompre une séance depuis le menu
Pause et de reprendre à l'étape validée.

Commandes utiles : `ZQSD` ou `WASD` pour se déplacer, souris ou flèches pour regarder, `E` pour agir,
`Tab` puis `Entrée` pour interagir sans souris, `H`/`F1` pour une aide et `Échap` pour la pause. Un
niveau peut toujours être réinitialisé depuis la pause. Le chronomètre du gymnase n'est qu'indicatif.

## Intentions et solutions

| Chapitre | Compétence mobilisée | Solution de référence |
|---|---|---|
| 2 — CDI | Exploration, classement d'informations | Fragments A/B/C, code `4-1-7` |
| 3 — Laboratoire | Déduction booléenne | `ON-OFF-ON-ON` |
| 4 — Auditorium | Mémoire séquentielle multimodale | jaune, rouge, vert, bleu |
| 5 — Gymnase | Orientation et planification spatiale | balises `1` à `5` ; temps sans sanction |
| 6 — Arts et musique | Formes, couleurs, alternance | cercle jaune, arc vert, colonne rouge |
| 7 — Collège secret | Réinvestissement multi-étapes | code `7-3-1`, relais `ON-ON-OFF`, symboles `2-4-1-3` |

Chaque activité propose trois niveaux d'aide. Les deux premières orientent la démarche ; la troisième
donne une solution explicite afin qu'aucun groupe ne reste bloqué. Dans l'auditorium, le texte du grand
afficheur reproduit toute information sonore. Une erreur de code, de logique, de séquence ou de motif
ne retire jamais les objets ou phases déjà acquis.

## Observation et évaluation

On peut observer la stratégie d'exploration, la capacité à formaliser une contrainte, l'usage raisonné
des aides et la coopération autour d'une mémoire externe. Le temps du gymnase ne doit pas servir de
condition de réussite. Pour rejouer une activité terminée, choisir `REJOUER` depuis le menu ; pour une
nouvelle campagne, utiliser `EFFACER LA PROGRESSION` puis confirmer.

Le fichier de sauvegarde est local à la session utilisateur et se nomme `campaign-v2.json` dans le
répertoire persistant Unity. Aucune donnée nominative n'est enregistrée.
