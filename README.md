# Chasse au Trésor du Collège 3D

Jeu éducatif d'exploration 3D réalisé avec Unity.

## Version

**1.0.0**

Unity **6000.3.2f1**

## Principe

Le joueur explore un collège et doit découvrir six indices dans le bon ordre avant de pouvoir ouvrir le trésor final.

Parcours :

1. Vie scolaire
2. CDI
3. Auditorium
4. Gymnase
5. Arts / Musique
6. Self élèves
7. Trésor

## Fonctionnalités

- exploration FPS 3D ;
- portes interactives ;
- six indices séquentiels ;
- coffre final ;
- mini-carte ;
- musique et bruitages ;
- halos animés ;
- effets de victoire ;
- personnages animés ;
- bâtiments aménagés ;
- textures PBR ;
- écran d'accueil ;
- menu Pause ;
- démonstration F2 ;
- bande-annonce F3 ;
- réglage du son et de la souris ;
- builds Linux, Windows et macOS préparés ;
- tests automatiques.

## Commandes

| Touche | Action |
|---|---|
| Z / W | Avancer |
| S | Reculer |
| Q / A | Aller à gauche |
| D | Aller à droite |
| Souris | Regarder |
| E | Interagir |
| M | Mini-carte |
| Échap | Pause |
| F2 | Démonstration |
| F3 | Bande-annonce |
| F10 | Quitter le jeu |

## Linux

Le build Linux 64 bits est disponible dans la Release GitHub `v1.0.0`.

## Windows

Le projet est prêt pour un build Windows 64 bits une fois le module Windows Build Support installé dans Unity.

## macOS

Le fichier `build-mac.command` permet de produire la version macOS Intel depuis un Mac équipé de Unity 6000.3.2f1.

Un profil graphique spécifique réduit certains réglages sur les anciens Mac Intel.
